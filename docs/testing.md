# Проверка

## Обязательный набор

```bash
pnpm typecheck
pnpm lint
pnpm check:structure
pnpm sim
pnpm check:assets
pnpm build
```

`pnpm check` = typecheck + lint + structure + sim. CI (`.github/workflows/deploy.yml`)
запускает `pnpm check`, `pnpm check:assets` и `pnpm build` перед публикацией.

## Sim-parity

`pnpm sim` компилирует `scripts/simulate-fight.ts` (TypeScript сам тянет граф) и
прогоняет 150 боёв на вид для политик skilled/pulse/hold/passive, плюс отдельный
tap-прогон (один кадр тяги в 0.9 с) на 5 боёв на вид. Вывод детерминирован:
`Math.random` подменяется seeded-генератором.

Кроме таблицы и коридоров sim проверяет:

- `sticky aim`, `feint lie`, `weight swing` — старые инварианты;
- `pause telegraph` / `pause calm` — рывок, замороженный паузой, сгорает на возврате,
  а пауза вне рывка ничего не меняет; доля пропуска при этом вливается постепенно;
- `miss cost` — один пропущенный рывок стоит половины escape-метра (и вливается за
  `missFillTime`), второй подряд рвёт рыбу, даже если она уже в круге;
- `opening grace` — в первые `startGrace` секунд ни одна рыба не телеграфирует и не
  выбрасывает рывок, а отложенный рывок всё равно приходит после грейса;
- `free counter` — удержание с прицелом против хода не даёт ни одного контра;
- `prepared grab` — нажатие в сектор рывка до открытия окна засчитывается, нажатие
  мимо сектора (в центр) — нет;
- `tap stall` — тап раз в 0.9 с не выигрывает и не оставляет бой открытым на 60 с;
- `fixed step` — 30 и 10 FPS дают то же время симуляции, длинный кадр режется
  кэпом 0.1 с.

Коридоры оракула: skilled ≥90 %, pulse 28–55 %, hold 5–25 %, passive 0; контр-игра
должна быть не меньше чем на 30 п.п. выше pulse. Правило: при рефакторинге без
изменения баланса вывод должен совпадать с baseline побайтово. При намеренном
изменении баланса обновляйте ожидаемые агрегаты в `docs/gameplay.md`.

## Ручной smoke

- boot, меню, «Как играть», кодекс;
- три водоёма: заброс, зона удачи, поклёвка, подсечка, бой (удержание/отдых/контр/
  финальный рывок), улов, промах, сбежавшая рыба;
- пауза, кодекс из паузы, mute, смена водоёма, потеря фокуса;
- перезагрузка: водоём, прогресс, mute, погода и полоса прогноза (после F5 — те
  же фронты, оставшееся время продолжает идти);
- `F2`: предпросмотр, reset, copy (не «В КОД» во время проверки);
- `F3`: смена фронта и пина часа в одной панели;
- в Network нет запросов удалённых ассетов (rock/rod), консоль без новых ошибок.

## Бюджет загрузки

Ориентиры из README: меню ~0.4 МБ, `ice-480.webp` 99 КБ в фоне, звуки 4.9 МБ,
скриншоты помощи ~96 КБ на idle. Замер:

```bash
pnpm build && pnpm preview
pnpm measure
```

`scripts/measure-load.mjs` запускает свежий Chrome; `--throttle=fast3g` и
`--software` — для медленного профиля.
