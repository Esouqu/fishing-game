# Зимняя рыбалка

Аркадная рыбалка на 10 забросов: подсекай вовремя, удерживай рыбу в круге у поплавка и собирай серию. Весь интерфейс — HUD, меню, таблица лидеров и пауза — отрисован в PixiJS, без DOM-оверлеев. Игру можно встроить в Svelte-приложение или запустить отдельной страницей.

## Возможности

- Ровно 10 забросов за сессию; результат попадает в локальную таблицу рекордов.
- Ботов-соперников с правдоподобными именами и счётом можно обогнать.
- 20 видов рыб с собственными повадками и темпераментом на каждый улов: рывки, дуги, паузы, финты. Перед сильным рывком рыба пускает пузыри, а у края появляется стрелка.
- Сила заброса выбирает дальность: у берега чаще клюёт обычная рыба, на глубине — реже, но дороже и злее.
- Шкала заброса без разметки глубин: дальность повышает шанс редкой рыбы и силу сопротивления, а узкая зона удачи даёт редкой рыбе дополнительный шанс.
- Рыба в круге видна силуэтом под водой; поплавок и леска следуют за ней, а пузыри и стрелка показывают, куда она рванёт.
- Зимняя сцена: снег вместо травы, сугробы, снежные шапки на деревьях и камнях, лёд у кромки воды, снег на пирсе и холодный градиент воды от бирюзового к тёмно-синему. На пирсе стоит фонарь, который загорается в сумерках и ночью.
- Смена дня и ночи и зимняя погода (ясно, облачно, снегопад, метель, морозный туман); часть рыбы клюёт только в своих условиях.
- Мир сохраняется между сессиями: время и погода идут, пока вы рыбачите.
- Скрытая удача растёт за идеальные уловы и обнуляется при срыве.
- Ранняя подсечка возвращает заброс; если рыба прошла мимо, поплавок остаётся в воде и ждёт следующую.
- Мини-игра вываживания: держи ЛКМ/пробел и веди прицел, отпускай кнопку для восстановления хватки, лови контррывки по пузырям и стрелке и делай финальный рывок, когда рыба выдохлась. Прицел против хода рыбы утомляет её быстрее; пузыри и стрелка показывают, куда рванёт рыба; при тяге поплавок идёт впереди рыбы.
- Выносливость рыбы и хватка — две полосы столбиком над кругом: сверху выносливость, снизу тонкая хватка с молнией. Хватка тратится на тягу и восстанавливается в покое; если выжать её до нуля, рыба на время выходит из-под контроля и успевает восстановиться. Когда рыба выходит из круга, у неё появляется дуга опасности; риск схода виден по тому, как поплавок уходит под воду и натягивается леска.
- Компактный гайд в правом нижнем углу не блокирует бой и не закрывается; полные правила всегда доступны в «Как играть».
- Серия: ×1 → ×1.25 → ×1.5 → ×1.75 → ×2. Срыв обнуляет серию и озвучивается.
- Процедурный звук на Web Audio: заброс, всплеск, поклёвка, катушка, фанфары; без внешних аудиофайлов.
- Локальное хранение рекордов и настроек, пауза при потере фокуса, адаптация под размер контейнера.
- Деревья, куст и камни — процедурная пиксельная графика со снежными шапками; генератор лежит в `scripts/make-nature-assets.py`.

## Быстрый старт

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm assets   # копирует графику из assetspacks/ и шрифт в public/assets/fishing
pnpm dev
```

Откройте адрес из вывода Vite. Без `pnpm assets` игра не найдёт текстуры и шрифт.

> Папка `assetspacks/` не хранится в git. Сгенерированные файлы в `public/assets/fishing/`, `public/assets/cursors/` и `public/favicon.png` добавлены в репозиторий для GitHub Pages. После обновления паков запустите `pnpm assets` и закоммитьте изменения. См. [CREDITS.md](./CREDITS.md).

## Управление

| Действие | Клавиатура | Мышь / тап |
| --- | --- | --- |
| Заброс | Пробел (зажать и отпустить) | ЛКМ / тап (зажать и отпустить) |
| Подсечка | Пробел в момент поклёвки | ЛКМ / тап |
| Вываживание | Зажать ЛКМ/пробел + вести прицел против хода / WASD / стрелки; отпустить — отдых; ПКМ/F — финальный рывок | Удержание + ведение пальцем; отпустить — отдых; тап по крючку — финальный рывок |
| Пауза | `Esc` / `P` | Кнопка паузы в HUD |
| Звук | — | Кнопка динамика в HUD |

## Как считаются очки

```
очки = очки рыбы × вес × множитель серии × бонус за идеальный улов
```

- **Вес** разыгрывается на каждую поимку внутри вида; крупная рыба даёт до +20% к очкам. Вес показывается только после поимки и в результатах.

- **Серия** растёт с каждой пойманной рыбой. Множитель применяется к следующему улову.
- **Идеально** — рыба покидала круг не больше двух раз; даёт ×1.5.
- Чем дальше заброс, тем выше шанс редкой рыбы, но ниже шанс частой.

## Встраивание в Svelte

Компонент лежит в `src/lib/FishingGame.svelte` (Svelte 5, runes).

```svelte
<script lang="ts">
  import FishingGame from "$lib/FishingGame.svelte";
</script>

<div style="height: 540px">
  <FishingGame
    onScore={(result) => console.log(result.score)}
    onExit={() => console.log("exit")}
  />
</div>
```

По умолчанию `assetBase` равен `${import.meta.env.BASE_URL}assets/fishing`, поэтому сборка работает и в корне домена, и в подпапке GitHub Pages. Пропс можно переопределить, если ассеты лежат в другом месте.

Пропсы: `assetBase`, `storagePrefix`, `muted`, `startScreen` (`"menu" | "game"`), `playerName`, `onExit`, `onScore`, `onReady`, `class`.

`playerName` — ник игрока из вашего стора; он автоматически записывается в локальную таблицу рекордов после каждой сессии, отдельного экрана ввода имени нет.

Компонент импортирует движок динамически, поэтому его можно рендерить при SSR. Экспортируемые методы экземпляра: `restart()`, `pause()`, `resume()`, `showMenu()`, `setMuted(value)`.

### Без Svelte

```ts
import { createFishingGame } from "./lib/fishing";

const game = await createFishingGame({
  container: document.getElementById("game")!,
  assetBase: `${import.meta.env.BASE_URL}assets/fishing`,
  storagePrefix: "quiet-cove",
  onScore: (result) => console.log(result),
});

// позже
game.destroy();
```

## GitHub Pages

В проект добавлен workflow `.github/workflows/deploy.yml`.

1. В настройках репозитория откройте **Settings → Pages**.
2. В **Build and deployment** выберите **GitHub Actions**.
3. Запушьте в `main` (или `master`); workflow соберёт `dist` и опубликует его.

Сборка использует `base: "./"`, поэтому подходит и для `https://<user>.github.io/<repo>/`, и для кастомного домена. `public/.nojekyll` уже добавлен, а пути к текстурам, шрифтам, курсорам и favicon берутся от `BASE_URL`.

### Ассеты

Исходные паки `assetspacks/` не входят в git, но необходимые для игры сгенерированные файлы (`public/assets/fishing/`, `public/assets/cursors/` и `public/favicon.png`) добавлены в репозиторий, поэтому чистый checkout GitHub Actions собирается без дополнительных шагов. `pnpm check:assets` проверяет, что они на месте.

После обновления исходных паков запустите `pnpm assets`, проверьте `pnpm check:assets` и закоммитьте обновлённые файлы. Условия использования графики — в [CREDITS.md](./CREDITS.md).

## Структура

```
src/
  main.ts                     отдельная страница-хост
  lib/
    FishingGame.svelte        Svelte 5-обёртка
    fishing/
      Game.ts                 жизненный цикл, экраны, ввод, resize
      world.ts                часы, погода, палитры дня и ночи
      config.ts               рыба, тайминги, дальность заброса, палитра
      types.ts                публичные типы
      utils.ts                подсчёт очков, weighted pick, форматирование
      storage.ts              рекорды, настройки и мир в localStorage
      audio.ts                процедурный Web Audio
      assets.ts               загрузка текстур
      screens/                меню, игра, помощь, рекорды, результаты
      game/                   сцена зимнего озера, мини-игра, чистая модель боя,
                              повадки, атмосфера
      ui/                     тема, кнопки, фокус, ScreenManager
scripts/sync-assets.mjs       копирование ассетов и шрифта
scripts/make-nature-assets.py зимние процедурные деревья, куст и камни
scripts/simulate-fight.ts     headless-балансировка боя
```
