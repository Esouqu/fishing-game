# Тихая заводь

Аркадная рыбалка на 10 забросов: подсекай вовремя, удерживай рыбу в зелёной зоне и собирай серию. Весь интерфейс — HUD, меню, таблица рекордов и пауза — отрисован в PixiJS, без DOM-оверлеев. Игру можно встроить в Svelte-приложение или запустить отдельной страницей.

## Возможности

- Ровно 10 забросов за сессию; результат попадает в локальную таблицу рекордов.
- Ботов-соперников с правдоподобными именами и счётом можно обогнать.
- Сила заброса выбирает зону: `МЕЛЬ` (частая рыба), `ГЛУБИНА` (баланс), `ОМУТ` (редкая и дорогая).
- Заряд заброса показывает конус возможного приземления, подсветку зоны и метку дальности.
- Мини-игра вываживания: зелёная зона, прогресс, две попытки на «идеальный» улов.
- Серия: ×1 → ×1.25 → ×1.5 → ×1.75 → ×2. Срыв обнуляет серию и озвучивается.
- Сундук — редкий бонус прямо во время лова.
- Процедурный звук на Web Audio: заброс, всплеск, поклёвка, катушка, фанфары; без внешних аудиофайлов.
- Локальное хранение рекордов и настроек, пауза при потере фокуса, адаптация под размер контейнера.

## Быстрый старт

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm assets   # копирует графику из assetspacks/ и шрифт в public/assets/fishing
pnpm dev
```

Откройте адрес из вывода Vite. Без `pnpm assets` игра не найдёт текстуры и шрифт.

> Папка `assetspacks/` и сгенерированные `public/assets/fishing/` не хранятся в git — это условия лицензий на графику. См. [CREDITS.md](./CREDITS.md).

## Управление

| Действие | Клавиатура | Мышь / тап |
| --- | --- | --- |
| Заброс | Пробел (зажать и отпустить) | ЛКМ / тап (зажать и отпустить) |
| Подсечка | Пробел в момент поклёвки | ЛКМ / тап |
| Вываживание | Пробел удерживать | ЛКМ / тап удерживать |
| Пауза | `Esc` / `P` | Кнопка паузы в HUD |
| Звук | — | Кнопка динамика в HUD |

## Как считаются очки

```
очки = очки рыбы × множитель серии × бонус за идеальный улов
```

- **Серия** растёт с каждой пойманной рыбой. Множитель применяется к следующему улову.
- **Идеально** — рыба не покидала зелёную зону больше двух раз; даёт ×1.5.
- **Сундук** добавляет фиксированный бонус.
- Чем дальше заброс, тем выше шанс редкой рыбы, но ниже шанс частой.

## Встраивание в Svelte

Компонент лежит в `src/lib/FishingGame.svelte` (Svelte 5, runes).

```svelte
<script lang="ts">
  import FishingGame from "$lib/FishingGame.svelte";
</script>

<div style="height: 540px">
  <FishingGame
    assetBase="/assets/fishing"
    onScore={(result) => console.log(result.score)}
    onExit={() => console.log("exit")}
  />
</div>
```

Пропсы: `assetBase`, `storagePrefix`, `muted`, `startScreen` (`"menu" | "game"`), `playerName`, `onExit`, `onScore`, `onReady`, `class`.

`playerName` — ник игрока из вашего стора; он автоматически записывается в локальную таблицу рекордов после каждой сессии, отдельного экрана ввода имени нет.

Компонент импортирует движок динамически, поэтому его можно рендерить при SSR. Экспортируемые методы экземпляра: `restart()`, `pause()`, `resume()`, `showMenu()`, `setMuted(value)`.

### Без Svelte

```ts
import { createFishingGame } from "./lib/fishing";

const game = await createFishingGame({
  container: document.getElementById("game")!,
  assetBase: "/assets/fishing",
  storagePrefix: "quiet-cove",
  onScore: (result) => console.log(result),
});

// позже
game.destroy();
```

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Дев-сервер Vite |
| `pnpm build` | Проверка типов и production-сборка в `dist/` |
| `pnpm preview` | Предпросмотр собранной версии |
| `pnpm typecheck` | `tsc --noEmit` |

## Структура

```
src/
  main.ts                     отдельная страница-хост
  lib/
    FishingGame.svelte        Svelte 5-обёртка
    fishing/
      Game.ts                 жизненный цикл, экраны, ввод, resize
      config.ts               рыба, тайминги, зоны воды, палитра
      types.ts                публичные типы
      utils.ts                подсчёт очков, weighted pick, форматирование
      storage.ts              рекорды и настройки в localStorage
      audio.ts                процедурный Web Audio
      assets.ts               загрузка текстур
      screens/                меню, игра, помощь, рекорды, результаты
      game/                   сцена озера, мини-игра, частицы
      ui/                     тема, кнопки, фокус, ScreenManager
scripts/sync-assets.mjs       копирование ассетов и шрифта
```
